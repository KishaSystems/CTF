# ORION CTF - Local Capture The Flag Environment

A self-contained, offline CTF you can play on your own machine. It has 11
challenges across Misc, Crypto, Forensics, Web, and Reversing, a scoring
system, hints that cost points, and local web challenges.

Everything uses the Python standard library. No internet, no Docker, no
third-party packages.

## Requirements

- Python 3.8 or newer (`python --version`; on Windows you may need `py --version`)

## Quick start

1. Build the challenge files (run once):

   ```
   python build.py
   ```

   On Windows you can also double-click `build.bat`. If `python` is not on
   your PATH, use `py build.py` instead. `python ctf.py` also builds
   automatically the first time it runs.

2. Start playing:

   ```
   python ctf.py
   ```

   On Windows you can also double-click `start.bat`.

3. Get the flag for a challenge, then submit it:

   ```
   python ctf.py submit misc-welcome CTF{...}
   ```

## Commands

| Command | What it does |
| --- | --- |
| `python ctf.py` | Interactive menu |
| `python ctf.py list` | List all challenges |
| `python ctf.py list crypto` | List one category |
| `python ctf.py show <id>` | Show description, files, and hint count |
| `python ctf.py hint <id>` | Reveal the next hint (costs 10% of the points) |
| `python ctf.py submit <id> <flag>` | Submit a flag |
| `python ctf.py score` | Show your score and progress bar |
| `python ctf.py serve <id>` | Start a local web challenge |
| `python ctf.py reset` | Reset all progress |

Challenge ids are listed by `python ctf.py list`. You can also use a unique
partial id, e.g. `python ctf.py show rsa`.

## Web challenges

Start a web challenge with:

```
python ctf.py serve web-robots
python ctf.py serve web-cookie
```

Then open <http://localhost:8000> in your browser. Stop the server with
`Ctrl+C`. Both web challenges use port 8000, so run one at a time.

## Scoring and hints

- Each challenge is worth its listed points.
- Each hint you reveal costs 10% of that challenge's base points.
- Points are locked in when you submit the correct flag.
- Progress is saved in `state/progress.json`.

## Resetting

```
python ctf.py reset
```

or delete the `state/` folder.

## Rules of engagement

This is a learning environment. Play fair:

- Do not open `build.py` if you want to solve the challenges honestly; it
  contains the plaintext flags used to generate the artifacts.
- Writeups are in `solutions/writeups.md`. Avoid reading them until you are
  stuck or finished.
- Everything runs locally. The web servers bind to localhost only.
